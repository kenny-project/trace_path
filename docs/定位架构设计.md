## 接口定义

### 1. MethodChannel（Flutter → Native）

| 方法名 | 参数 | 返回 | 说明 |
|--------|------|------|------|
| `startLocationService` | `{interval: int, powerSaving: bool, accuracy: string}` | `bool` | 启动定位服务 |
| `stopLocationService` | - | `bool` | 停止定位服务 |
| `updateLocationConfig` | `{interval: int, powerSaving: bool, accuracy: string}` | `bool` | 更新配置 |
| `isLocationServiceRunning` | - | `bool` | 查询服务状态 |

**Accuracy 选项**：
- `best` - 最高精度
- `medium` - 中等精度
- `low` - 低精度（省电）

---

### 2. EventChannel（Native → Flutter）

| 事件类型 | 数据结构 | 说明 |
|----------|----------|------|
| `location` | `{latitude: double, longitude: double, accuracy: double, altitude: double, speed: double, timestamp: int}` | 位置更新 |
| `error` | `{code: string, message: string}` | 错误信息 |
| `serviceStatus` | `{running: bool}` | 服务状态变化 |

## Android 实现

### 职责
- 启动 ForegroundService（保活）
- 管理 FusedLocationProviderClient
- 实现定位循环（定时调用 getCurrentLocation）
- 通过 EventChannel 推送位置给 Flutter

### 文件
```
android/app/src/main/kotlin/.../
├── LocationForegroundService.kt   # 前台服务
├── LocationPlugin.kt              # FlutterPlugin (MethodChannel + EventChannel)
└── NativeLocationHandler.kt       # 定位逻辑（已有，可复用）
```

### 服务生命周期
```
startLocationService()
  → 创建 ForegroundService
  → 配置 LocationRequest (interval, accuracy)
  → 启动 while 循环获取位置
  → 通过 EventChannel 推送位置

stopLocationService()
  → 停止循环
  → 停止 ForegroundService
```

## iOS 实现

### 职责
- 使用 CLLocationManager
- 实现 LocationManagerDelegate
- 通过 EventChannel 推送位置给 Flutter

### 文件
```
ios/Runner/
├── LocationPlugin.swift           # FlutterPlugin
└── AppDelegate.swift             # 注册插件
```

### 特点
- iOS 不需要 ForegroundService
- 使用 `allowsBackgroundLocationUpdates = true`
- 使用 `pausesLocationUpdatesAutomatically = false`

## Flutter 实现

### 职责
- 通过 MethodChannel 启动/停止原生定位服务
- 通过 EventChannel 接收位置
- 广播位置给 UI 层

### 关键代码

```dart
class BackgroundLocationService {
  // 原生服务控制
  Future<bool> start() async {
    await _methodChannel.invokeMethod('startLocationService', {
      'interval': _intervalSeconds,
      'powerSaving': _powerSaving,
      'accuracy': 'best',
    });
    return true;
  }

  // 位置接收（EventChannel）
  void _initLocationStream() {
    _eventChannel.receiveBroadcastStream().listen((event) {
      if (event is Map) {
        final position = Position(...);
        _broadcast(LocationEvent.position(position));
      }
    });
  }
}
```

## 共用部分

| 部分 | 说明 |
|------|------|
| `BackgroundLocationService` | Flutter 层，统一接口 |
| `MethodChannel` 协议 | 启动/停止/配置命令 |
| `EventChannel` 协议 | 位置推送格式 |
| `Position` 数据结构 | 统一的坐标数据 |

---

## 不需要改动的部分

| 部分 | 说明 |
|------|------|
| `LocationProvider` 接口 | 可保留，NativeLocationProvider 改作配置层 |
| `GeolocatorLocationProvider` | 可删除，iOS 用原生实现 |
| UI 层 | 订阅/广播机制不变 |
| 定位通知 | 不涉及 |
